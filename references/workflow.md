# Workflow Reference

Stage order: inspect, structure map, mental models, argument tree, controversies, cognitive risks, high-order questions, Socratic tutor, error system, Feynman test, real-world transfer, attack the author, personal knowledge system, final assessment, knowledge-tree synthesis, knowledge-tree validation, SVG/Markdown rendering, optional PNG rendering, user-facing visual delivery.

Mark every claim as original explicit content, synthesis from original content, AI inference, or external knowledge.

## Knowledge Tree Delivery

Use `knowledge_tree.json` as the structured source of truth. The Agent performs the synthesis; the renderer only turns the JSON into `19_全书知识树.md`, `19_全书知识树.svg`, and optional `19_全书知识树.png`.

The knowledge tree is not a chapter outline. Chapters, pages, units, and chunks are source locations. The tree itself is knowledge-centric: root question, core thesis, core modules, knowledge points, mechanisms, cases, boundaries, misconceptions, provenance, confidence, and verified source IDs.
